# AI Bot Task Assignment - Frontend Integration Guide

## 🎯 Overview

Admins can now **assign tasks to the AI chatbot** from the frontend dashboard! Tasks can be created manually or auto-generated by the bot during conversations.

## 🚀 Features

✅ **Create Tasks** - Assign work to the bot (send emails, create tickets, process refunds, etc.)  
✅ **Auto-Tasks** - Bot creates tasks automatically during conversations  
✅ **Assign to Admins** - Delegate tasks to specific team members  
✅ **Bulk Assignment** - Assign multiple tasks at once  
✅ **Priority Levels** - Low, Medium, High, Urgent  
✅ **Task Types** - 8 pre-defined types + custom  
✅ **Status Tracking** - Pending → Processing → Completed/Failed  
✅ **Analytics** - Task stats and distribution reports

---

## 📋 Task Types

| Type               | Description           | Use Case                       |
| ------------------ | --------------------- | ------------------------------ |
| `create_ticket`    | Create support ticket | Bot escalates issue to human   |
| `send_email`       | Send email to user    | Welcome emails, notifications  |
| `update_order`     | Update order status   | Process cancellations, refunds |
| `process_refund`   | Handle refund request | Automated refund processing    |
| `enroll_student`   | Enroll in course      | Bulk enrollments, promotions   |
| `send_certificate` | Issue certificate     | Upon course completion         |
| `schedule_session` | Schedule live session | Arrange makeup sessions        |
| `custom`           | Custom task           | Any other workflow             |

## 🎨 Priority Levels

- **Low** - Can wait, no urgency
- **Medium** - Normal priority (default)
- **High** - Important, needs attention soon
- **Urgent** - Critical, immediate action required

## 📊 Task Status

- **Pending** - Waiting to be assigned
- **Processing** - Admin working on it
- **Completed** - Task finished successfully
- **Failed** - Task couldn't be completed
- **Cancelled** - Task no longer needed

## 📡 API Endpoints

### Base URL: `/api/ai-bot/tasks`

### 1. **Create Task (Manual Assignment)**

```http
POST /ai-bot/tasks
```

**Headers:**

```
Authorization: Bearer <ADMIN_TOKEN>
```

**Request Body:**

```json
{
  "taskType": "send_email",
  "title": "Send welcome email to new student",
  "description": "User John Doe just enrolled, send welcome package",
  "priority": "high",
  "userId": "user-id-here",
  "taskData": {
    "email": "john@example.com",
    "templateName": "welcome",
    "variables": {
      "firstName": "John",
      "courseName": "Web Development Bootcamp"
    }
  },
  "scheduledFor": "2025-11-12T10:00:00Z"
}
```

**Response:**

```json
{
  "_id": "task-id",
  "taskType": "send_email",
  "title": "Send welcome email to new student",
  "status": "pending",
  "priority": "high",
  "createdBy": "admin-id",
  "createdAt": "2025-11-11T05:00:00Z"
}
```

### 2. **Get All Tasks (with Filters)**

```http
GET /ai-bot/tasks?page=1&limit=20&status=pending&priority=high
```

**Query Parameters:**

- `page` - Page number (default: 1)
- `limit` - Items per page (default: 20)
- `status` - Filter by status (pending, processing, completed, failed)
- `priority` - Filter by priority (low, medium, high, urgent)
- `assignedTo` - Filter by assigned admin ID
- `taskType` - Filter by task type

**Response:**

```json
{
  "tasks": [
    {
      "_id": "task-1",
      "taskType": "create_ticket",
      "title": "Technical support needed",
      "description": "User reported video playback issue",
      "status": "pending",
      "priority": "high",
      "userId": {
        "_id": "user-id",
        "firstName": "John",
        "lastName": "Doe",
        "email": "john@example.com"
      },
      "assignedTo": null,
      "createdBy": {
        "_id": "admin-id",
        "firstName": "Admin",
        "lastName": "User"
      },
      "conversationId": "conv-id",
      "taskData": {
        "issueType": "technical",
        "description": "Video won't load..."
      },
      "createdAt": "2025-11-11T04:30:00Z"
    }
  ],
  "pagination": {
    "total": 45,
    "page": 1,
    "limit": 20,
    "totalPages": 3
  }
}
```

### 3. **Get Single Task**

```http
GET /ai-bot/tasks/:id
```

### 4. **Update Task**

```http
PUT /ai-bot/tasks/:id
```

**Request Body:**

```json
{
  "status": "completed",
  "result": "Email sent successfully to john@example.com"
}
```

### 5. **Assign Task to Admin**

```http
POST /ai-bot/tasks/:id/assign
```

**Request Body:**

```json
{
  "assignedTo": "admin-user-id"
}
```

**Response:**

```json
{
  "_id": "task-id",
  "status": "processing",
  "assignedTo": "admin-user-id",
  "startedAt": "2025-11-11T05:15:00Z"
}
```

### 6. **Bulk Assign Tasks**

```http
POST /ai-bot/tasks/bulk/assign
```

**Request Body:**

```json
{
  "taskIds": ["task-1", "task-2", "task-3"],
  "assignedTo": "admin-user-id"
}
```

**Response:**

```json
{
  "assigned": 3,
  "total": 3
}
```

### 7. **Get Task Statistics**

```http
GET /ai-bot/tasks/stats
```

**Response:**

```json
{
  "total": 150,
  "pending": 25,
  "processing": 15,
  "completed": 105,
  "failed": 5,
  "priorityDistribution": [
    { "_id": "high", "count": 30 },
    { "_id": "medium", "count": 90 },
    { "_id": "low", "count": 30 }
  ],
  "taskTypeDistribution": [
    { "_id": "create_ticket", "count": 50 },
    { "_id": "send_email", "count": 40 },
    { "_id": "process_refund", "count": 25 },
    { "_id": "custom", "count": 35 }
  ]
}
```

### 8. **Delete Task**

```http
DELETE /ai-bot/tasks/:id
```

## 🎨 Frontend Integration (React Example)

### Task Management Dashboard

```tsx
// pages/admin/bot-tasks.tsx
import { useState, useEffect } from 'react';
import axios from 'axios';

export default function BotTasksDashboard() {
  const [tasks, setTasks] = useState([]);
  const [stats, setStats] = useState(null);
  const [filters, setFilters] = useState({
    status: 'pending',
    priority: '',
    page: 1,
  });

  useEffect(() => {
    fetchTasks();
    fetchStats();
  }, [filters]);

  const fetchTasks = async () => {
    try {
      const { data } = await axios.get('/api/ai-bot/tasks', {
        params: filters,
        headers: { Authorization: `Bearer ${getToken()}` },
      });
      setTasks(data.tasks);
    } catch (error) {
      console.error('Failed to fetch tasks:', error);
    }
  };

  const fetchStats = async () => {
    try {
      const { data } = await axios.get('/api/ai-bot/tasks/stats', {
        headers: { Authorization: `Bearer ${getToken()}` },
      });
      setStats(data);
    } catch (error) {
      console.error('Failed to fetch stats:', error);
    }
  };

  const assignTask = async (taskId: string, adminId: string) => {
    try {
      await axios.post(
        `/api/ai-bot/tasks/${taskId}/assign`,
        { assignedTo: adminId },
        { headers: { Authorization: `Bearer ${getToken()}` } },
      );
      alert('Task assigned successfully!');
      fetchTasks();
    } catch (error) {
      alert('Failed to assign task');
    }
  };

  const assignToMe = async (taskId: string) => {
    const myUserId = getCurrentUserId();
    await assignTask(taskId, myUserId);
  };

  const completeTask = async (taskId: string, result: string) => {
    try {
      await axios.put(
        `/api/ai-bot/tasks/${taskId}`,
        { status: 'completed', result },
        { headers: { Authorization: `Bearer ${getToken()}` } },
      );
      alert('Task completed!');
      fetchTasks();
    } catch (error) {
      alert('Failed to update task');
    }
  };

  const bulkAssign = async (taskIds: string[], adminId: string) => {
    try {
      const { data } = await axios.post(
        '/api/ai-bot/tasks/bulk/assign',
        { taskIds, assignedTo: adminId },
        { headers: { Authorization: `Bearer ${getToken()}` } },
      );
      alert(`${data.assigned} tasks assigned successfully!`);
      fetchTasks();
    } catch (error) {
      alert('Failed to bulk assign');
    }
  };

  return (
    <div className="task-dashboard">
      <h1>AI Bot Task Manager</h1>

      {/* Stats Overview */}
      {stats && (
        <div className="stats-grid">
          <div className="stat-card">
            <h3>Total Tasks</h3>
            <p className="stat-number">{stats.total}</p>
          </div>
          <div className="stat-card pending">
            <h3>Pending</h3>
            <p className="stat-number">{stats.pending}</p>
          </div>
          <div className="stat-card processing">
            <h3>Processing</h3>
            <p className="stat-number">{stats.processing}</p>
          </div>
          <div className="stat-card completed">
            <h3>Completed</h3>
            <p className="stat-number">{stats.completed}</p>
          </div>
        </div>
      )}

      {/* Filters */}
      <div className="filters">
        <select
          value={filters.status}
          onChange={(e) => setFilters({ ...filters, status: e.target.value })}
        >
          <option value="">All Status</option>
          <option value="pending">Pending</option>
          <option value="processing">Processing</option>
          <option value="completed">Completed</option>
          <option value="failed">Failed</option>
        </select>

        <select
          value={filters.priority}
          onChange={(e) => setFilters({ ...filters, priority: e.target.value })}
        >
          <option value="">All Priorities</option>
          <option value="urgent">Urgent</option>
          <option value="high">High</option>
          <option value="medium">Medium</option>
          <option value="low">Low</option>
        </select>
      </div>

      {/* Task List */}
      <div className="task-list">
        {tasks.map((task) => (
          <div key={task._id} className={`task-card priority-${task.priority}`}>
            <div className="task-header">
              <span className={`badge ${task.taskType}`}>
                {task.taskType.replace('_', ' ')}
              </span>
              <span className={`priority-badge ${task.priority}`}>
                {task.priority}
              </span>
              <span className={`status-badge ${task.status}`}>
                {task.status}
              </span>
            </div>

            <h3>{task.title}</h3>
            <p>{task.description}</p>

            {task.userId && (
              <div className="task-user">
                <strong>Related to:</strong> {task.userId.firstName}{' '}
                {task.userId.lastName}
                <br />
                <small>{task.userId.email}</small>
              </div>
            )}

            {task.assignedTo ? (
              <div className="assigned-to">
                <strong>Assigned to:</strong> {task.assignedTo.firstName}{' '}
                {task.assignedTo.lastName}
              </div>
            ) : (
              <button
                className="btn-assign-me"
                onClick={() => assignToMe(task._id)}
              >
                Assign to Me
              </button>
            )}

            {task.status === 'processing' &&
              task.assignedTo?._id === getCurrentUserId() && (
                <div className="task-actions">
                  <button
                    className="btn-complete"
                    onClick={() => {
                      const result = prompt('Enter completion notes:');
                      if (result) completeTask(task._id, result);
                    }}
                  >
                    Mark as Complete
                  </button>
                  <button
                    className="btn-fail"
                    onClick={() => {
                      const error = prompt('Enter failure reason:');
                      if (error) {
                        axios.put(
                          `/api/ai-bot/tasks/${task._id}`,
                          { status: 'failed', errorMessage: error },
                          {
                            headers: { Authorization: `Bearer ${getToken()}` },
                          },
                        );
                      }
                    }}
                  >
                    Mark as Failed
                  </button>
                </div>
              )}

            <small className="task-date">
              Created {new Date(task.createdAt).toLocaleString()}
            </small>
          </div>
        ))}
      </div>
    </div>
  );
}
```
